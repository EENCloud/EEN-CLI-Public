Brivo Video CLI Manual

NAME

brivo video - A command-line tool for managing and retrieving information related to cameras, bridges, users, and more in a cloud-based environment.

SYNOPSIS

brivo video [OPTIONS] <object> <command> [ARGS]

DESCRIPTION

The brivo video CLI provides various commands to interact with cameras, bridges, users, sites, and other resources. It offers multiple options for fetching information in different formats (CSV, tree structure, etc.) and supports both standard and v1 APIs.

Options:

  • --help, -h Displays the help information for the brivo video command or a specific object.

  • --version Displays the current version of the brivo video CLI.

COMMANDS

Version

brivo --version

Displays the version of the brivo video CLI.

Help

brivo help

Shows detailed help instructions. For shorter help on a specific object, use:

brivo video <object> --help

General Options:

General options are available for all commands that include [general-options] in their usage.

  • --call-time Display api response time.
  • -d, --debug Display detailed debug output.
  • -h, --help Display how to execute the selected subcommand and provides usage examples.
  • --prompt Display user confirmation prompts.
  • --time Display time taken to execute the command.

Note: --prompt may be unavailable for some commands.

EXAMPLES

brivo help
brivo --help
brivo -h
brivo auth --help
brivo video camera list --help

Time

Shows the execution time of the command, use:

brivo video <object> [COMMAND] [options] --time

Call Time

Shows the time taken to get response from api, use:

brivo video <object> [COMMAND] [options] --call-time

auth

NAME

auth - authentication commands for Eagle Eye video and Brivo access control

SYNOPSIS

brivo auth [COMMAND] [options]

DESCRIPTION

The brivo auth command provides utilities for logging in and out of Eagle Eye video and Brivo access control. By default, auth login and auth logout operate on both services. Use -v/--video or -a/--access to target a single service.

When logging in, the user is redirected to a login URL and completes authentication in the web browser. The --v1 option authenticates directly through the CLI using username and password (Eagle Eye video only). Note: The --v1 option is deprecated.

COMMANDS

login

Log in to Eagle Eye video, Brivo access control, or both.

Usage:

brivo auth login [options] [general options]

Options:

  • -v, --video Login only to Eagle Eye video.
  • -a, --access Login only to access control.
  • -p, --password <password> Password for login (Eagle Eye video only). Use quotes around the password if it contains special characters (e.g., --password "MyP@ssw0rd!").
  • -u, --username <username> Username for login (Eagle Eye video only, e.g., --username admin@example.com).
  • --v1 Use v1 api (Eagle Eye video only). Requires --username and --password (deprecated).

Notes:

  • --password, --username and --v1 are Eagle Eye video-only options and cannot be combined with --access.
  • Without any flag, login is attempted for both Eagle Eye video and access control.

EXAMPLES

  • Login to both Eagle Eye video and access control (browser-based):
brivo auth login
  • Login to Eagle Eye video only (browser-based):
brivo auth login --video
  • Login to Eagle Eye video using v1 API:
brivo auth login --video --v1 --username johndoe --password secret
  • Login to access control only (browser-based):
brivo auth login --access

logout

Log out of Eagle Eye video, Brivo access control, or both.

Usage:

brivo auth logout [options] [general options]

Options:

  • -v, --video Logout only from Eagle Eye video.
  • -a, --access Logout only from access control.

Notes:

  • Without any flag, logout is attempted for all logged-in services. No error is shown if one service is not logged in - only if both are not logged in.
  • --video and --access cannot be combined.

EXAMPLES

  • Logout from both services:
brivo auth logout
  • Logout from Eagle Eye video only:
brivo auth logout --video
  • Logout from access control only:
brivo auth logout --access

list

List all logged-in users across Eagle Eye video and Brivo access control. At least one service must be logged in.

Usage:

brivo auth list [options] [general options]

Options:

  • --csv Display details in CSV format.
  • --header Display column headers in the result.
  • --include [value1, value2] Display associated items (supported values: account-id, user-id, account-name, user-name, account-type, platform).
  • -l, --long Display full details including account ID, user ID, account name, user name, account type, and platform.

EXAMPLES

  • List all logged-in users:
brivo auth list
  • List with column headers:
brivo auth list --header
  • List with full details:
brivo auth list --long

Output

Short format:

Account
Jibi Joseph(ca08135f) [video]
Jibi Joseph(10145329) [access]

Long format (-l):

Account Id    User Id    Account Name          User Name     Account Type    Platform
ca08135f      ...        My EEN Account        Jibi Joseph   reseller        video
10145329      ...        Brivo CLI Testing     Jibi Joseph   -               access

switch

Switch to a different logged-in user. Use -v/--video for Eagle Eye video accounts or -a/--access for Brivo access control (one of them is required). To switch into a sub-account, use brivo video account switch.

Usage:

brivo auth switch [options] [general options]

Options:

  • -v, --video Switch Eagle Eye video user.
  • -a, --access Switch Brivo access control user.
  • --user-id [user id] Specify the user ID to switch to.
  • --username [username] Specify the username to switch to.

EXAMPLES

  • Switch Eagle Eye video user by user ID:
brivo auth switch --video --user-id <user ID>
  • Switch Eagle Eye video user by username:
brivo auth switch --video --username johndoe@example.com
  • Switch Brivo access control user:
brivo auth switch --access --user-id <user ID>

Notes:

  • Exactly one of --video or --access must be provided. They cannot be used together.
  • Either --user-id or --username must be provided.
  • To switch into a reseller sub-account, use brivo video account switch instead.

user - Manage Users

NAME

user - manage and interact with users.

SYNOPSIS

brivo video user [COMMAND] [OPTIONS]

DESCRIPTION

The user command allows you to manage users, list user permissions, and export user data in various formats.

COMMANDS

list

List users.

Usage:

brivo video user list [options] [selectors] [general options]

Options:

  • --csv Display details in CSV format.
  • --json List details in JSON format.
  • -f, --file-name [file name] Specify the name of the file where the output will be saved.
  • -g, --google-sheet Display details in CSV format in google sheet.
  • --header Display column headers in the result.
  • --html Generate a chart in an HTML file.
  • --include [value1, value2] Display associated items (supported values: email, firstname, id, lastname, permission, status).
  • -l, --long Display details of user including language, last login, login status, permissions, and either accessible cameras (end user accounts) or accessible accounts (reseller accounts).

Selectors:

  • --email [email-id1, email-id2] Filter by email ID.
  • --firstname [first-name1, first-name2] Filter by first name.
  • --id [id1, id2] Filter by user ID.
  • --lastname [last-name1, last-name2] Filter by last name.
  • --status [status1, status2] Filter by status (supported values: active, pending, blocked).

Actions:

  • If --html is specified, generate a user permissions report.
  • If --csv is specified, export users in CSV format.
  • If --json is specified, export users in JSON format.
  • If --google-sheet is specified, export and upload user data to Google Sheets.

EXAMPLES

  • To list all users:
brivo video user list --header --csv

Output

"id","account id","first name","last name"
"ca046095","00052029","Anandhakrishnan","M"
"ca01060e","00052029","Anandhan","Sreekumar"
  • To list users in CSV format:
brivo video user list --csv -f users.csv
  • To generate an HTML report of user permissions:
brivo video user list --html
  • To list all users with full details (reseller account):
brivo video user list --long --header

Output (reseller)

"id","account id","first name","last name","e-mail","accounts","language","last login","login status","permissions"
"ca046095","00052029","John","Doe","john@example.com","Acme Corp [00195229], Widget Co [00195230]","en","2024-01-15T10:00:00Z","active","administrator"

Note: For reseller accounts, the --long flag shows an Accounts column listing all sub-accounts each user can access in account_name [account_id] format. For end user accounts, it shows an Accessible Cameras column instead.

set

Update rules matching the given selectors.

DESCRIPTION

The rule set command allows you to update a specific field for one or more rules at once. You can specify the field to change as <parameter>, and the new value as <value>. Use selectors (like --rule-type, --camera, --enabled, etc.) to target specific rules — every rule matched by the selectors is updated, and a summary table reports the outcome for each one, so a single invocation can update many rules at the same time.

Most parameters only apply to certain rule types (noted below as "supported by"). If a matched rule's type doesn't support the parameter being set, that rule is reported as failed in the output with the reason, while every other matched rule is still updated.

Usage:

brivo video rule set [parameter] [value] [options] [selectors] [general options]

Parameters:

  • action-id <id1, id2> Set action ids (supported by: all types).
  • action-name <name1, name2> Set action names (supported by: all types).
  • alert-time <HH:MM> Set the alert time (24-hour) (supported by: overstay).
  • camera <camera1, camera2> Set camera names (supported by: intrusionDetection, loitering, motionDetection, motionRegionDetection, objectLineCross, thermalThresholdCrossed, vehicleDetection, personDetection, eevaQuery, gunDetection, slipAndFall, crowdFormation, ppeViolation, fireAndSmokeDetection, allowedVehicle, deniedVehicle, countOfLicensePlate, unregisteredVehicle, hotlistVehicle, wrongWay, overstay).
  • count <count> Set the count (supported by: countOfLicensePlate).
  • destination-camera <camera1, camera2> Set destination camera names (supported by: watchVehicle).
  • destination-esn <esn1, esn2> Set destination camera esns (supported by: watchVehicle).
  • device-id <id1, id2> Set device ids (supported by: inputTriggered, deviceStatus).
  • device-name <name1, name2> Set device names (supported by: inputTriggered, deviceStatus).
